What can an SEO/GEO audit actually prove?

Published 14 October 2026

A website check can show an observable barrier or a clearer next step. It cannot establish search rankings or AI recommendations from crawler access alone. Separate the evidence you can inspect today from the outcomes you need to measure over time.

Start with access, then check outcomes

Google says pages supporting AI Overviews or AI Mode must be indexed and eligible for a search snippet. Meeting those requirements does not guarantee crawling, indexing or appearance. Its existing SEO foundations still apply; there is no special AI schema requirement. See Google’s AI features guidance.

OpenAI distinguishes OAI-SearchBot, used for search discovery, from GPTBot, used for potential training. Treat their policies separately. Allowing a search crawler is an access decision, not proof that your business will be cited. See OpenAI’s crawler documentation.

Four questions to ask before paying for an audit

  1. What was actually collected? Ask for sampled URLs, dates and relevant excerpts. An unavailable response is unknown. A collector size limit is a collection limitation, not a website defect.
  2. Does each proposed task follow from its evidence? A title can describe the wrong offer; an intentional crawler block can be correct. Ask which observation supports the change and when you should leave the page alone.
  3. What would count as a successful fix? Define a reproducible check: the intended directive is present, the title describes the verified offer, or the proposed copy matches actual capabilities.
  4. Which outcomes remain unmeasured? A technical fix and a customer acquisition result need separate evidence. Ask for denominators and dates before accepting a percentage improvement.

A small example: an intentional crawler block

Suppose a sampled robots.txt blocks a search crawler. The observation supports checking the owner’s policy. It does not automatically support removing the block. If search discovery is intended, inspect the matching crawler group and hosting controls before proposing a targeted change. If the block is intentional, make no change. This is a hypothetical example, not a customer finding.

Measure the result at the right level

First reproduce the changed page or directive. For Google search outcomes, compare dated Search Console data over declared periods; Google includes its AI search features in overall Web performance reporting. That aggregate does not isolate an AI-only uplift. For an AI mention check, record the engine, interface, date and prompt sample, retain the actual responses, and report observed mentions over the number of checks. Treat a small sample as a sample, not a universal visibility score.
